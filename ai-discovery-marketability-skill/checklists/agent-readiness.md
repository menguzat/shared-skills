# Agent Readiness Checklist

- [ ] Native semantic elements used for controls where possible.
- [ ] Buttons/links have accessible names.
- [ ] Form fields have deterministic labels.
- [ ] State changes are represented semantically.
- [ ] Product variants can be selected without visual-only inference.
- [ ] Price/availability are textually/structurally available.
- [ ] Add-to-cart/checkout path is deterministic.
- [ ] Errors are explicit and actionable.
- [ ] No essential action depends only on hover/gesture.
- [ ] URLs/history reflect important navigation state where appropriate.
- [ ] Authentication/consent barriers are understood.
- [ ] Checkout, returns, support contact are explicit.

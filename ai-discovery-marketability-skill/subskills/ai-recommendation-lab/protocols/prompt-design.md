# Prompt Design Protocol

Use four families:
1. category-neutral discovery,
2. constraint qualification,
3. comparative selection,
4. trust/verification.

Within each family:
- create 3–10 paraphrases,
- preserve intent,
- vary one decision dimension at a time for boundary tests,
- avoid leading the model toward the target brand unless explicitly testing branded trust queries,
- randomize named candidate order in direct comparison experiments.

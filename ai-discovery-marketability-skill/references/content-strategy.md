# Content Strategy for Search + AI Discovery

Priority order:
1. first-hand/source-native evidence,
2. decision-critical facts,
3. original analysis/data/methods,
4. useful comparisons/tradeoffs,
5. supporting education/context,
6. promotional narrative.

Commodity content that an LLM can generate from common knowledge should not dominate the content plan unless it serves a clear user need and adds unique value.

Good content artifacts:
- tested measurements/results,
- real case studies,
- documented production/process,
- transparent specifications,
- expert methods,
- actual comparison tables,
- original images/video,
- provenance records,
- versioned policy and availability information.

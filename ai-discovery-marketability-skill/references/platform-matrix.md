# Platform Matrix — verify before use

## Google Search / AI Overviews / AI Mode
- Foundation remains normal Search eligibility/indexing and core Search systems.
- Current official guidance emphasizes valuable, unique, non-commodity content.
- No special AI schema is required.
- Google states `llms.txt` is not used for Google Search/generative Search.
- Merchant Center and Business Profile can feed shopping/local visibility.
- Google documents query fan-out for generative Search experiences.
- UCP is an emerging official commerce protocol for agentic actions on Google surfaces.

Official references:
- https://developers.google.com/search/docs/fundamentals/ai-optimization-guide
- https://developers.google.com/search/docs/appearance/ai-features
- https://developers.google.com/search/docs/fundamentals/seo-starter-guide
- https://developers.google.com/search/docs/appearance/structured-data/merchant-listing
- https://developers.google.com/merchant/ucp

## OpenAI / ChatGPT Search / Commerce
- OAI-SearchBot is documented for ChatGPT search discovery.
- GPTBot is separately documented for potential training use.
- Product feeds can provide current structured catalog data for ChatGPT product discovery where available.
- Agentic Commerce Protocol is documented for merchant/ChatGPT commerce integration.

Official references:
- https://developers.openai.com/api/docs/bots
- https://developers.openai.com/commerce
- https://developers.openai.com/commerce/specs/file-upload/products

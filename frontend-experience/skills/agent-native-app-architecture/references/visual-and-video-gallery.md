## Visual-study exercise for the agent

When designing a new product, select 3–5 examples from this gallery and explicitly compare:

- where intent enters
- what is fixed vs generated
- how state remains visible
- how the user directly manipulates output
- how conversation and workspace coexist
- how approval/error/progress is represented

Do not copy visual styling blindly. Extract interaction principles.

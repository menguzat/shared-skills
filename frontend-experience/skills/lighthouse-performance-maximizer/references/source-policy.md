# Source and Evidence Policy

Use four evidence classes:

- **OFFICIAL** — current Chrome/Lighthouse/web.dev/framework documentation or observed tool output.
- **ESTABLISHED** — broadly accepted performance engineering practice supported by multiple reliable sources.
- **HEURISTIC** — useful default that may vary by app, architecture, browser, or workload.
- **HYPOTHESIS** — project-specific causal claim requiring measurement.

Rules:

1. Installed Lighthouse output/version outranks remembered score details.
2. Official Chrome/web.dev documentation outranks third-party optimization posts for Lighthouse/Web Vitals definitions.
3. Never promote a one-site experiment into a universal rule.
4. Record source date because performance APIs, scoring, and browser behavior evolve.
5. Public skills may inform workflow design but should not be treated as browser/platform specifications.

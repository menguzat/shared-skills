- [ ] Long tasks attributed to source.
- [ ] Startup vs interaction work separated.
- [ ] Unused dependencies/features identified.

- [ ] Long synchronous work can yield or move off-main-thread where appropriate.
- [ ] Improvement verified in TBT/trace and field INP where available.

# Image Checklist

- [ ] LCP image identified per representative route.
- [ ] LCP image is not lazy-loaded.
- [ ] LCP resource is discoverable early.
- [ ] Responsive candidate matches rendered size.
- [ ] Intrinsic dimensions/aspect ratio reserve space.
- [ ] Offscreen images are lazy-loaded where beneficial.
- [ ] Modern encoding/compression evaluated without unacceptable quality loss.
- [ ] Image CDN/cache behavior verified.
- [ ] Multiple `fetchpriority=high` assets are not competing unnecessarily.
- [ ] Decorative images have appropriate semantics.

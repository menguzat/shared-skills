# Font Checklist

- [ ] Above-fold font files identified.
- [ ] Unused weights/styles removed or deferred.
- [ ] Critical preload count is minimal and justified.
- [ ] `font-display` policy is intentional.
- [ ] Fallback metrics/CLS assessed.
- [ ] Font subsets and file sizes inspected.
- [ ] Cross-origin/preconnect settings are justified.
- [ ] Brand typography preserved unless change approved.

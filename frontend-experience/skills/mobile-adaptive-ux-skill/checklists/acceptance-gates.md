# Acceptance Gates

A redesign fails if any applicable critical item is false.

## Critical
- [ ] P0 tasks are reachable and completable.
- [ ] No critical functionality is hover-only.
- [ ] Browser Back is not broken by overlays/subviews.
- [ ] User zoom is not disabled.
- [ ] No compact width has an unintended horizontal page scroll.
- [ ] Software keyboard does not make required form progression impossible.
- [ ] Desktop P0 tasks still work.

## Strong quality
- [ ] Navigation is chosen from task structure, not fashion.
- [ ] Mobile is not merely a stacked desktop page.
- [ ] Secondary complexity uses deliberate progressive disclosure.
- [ ] Applied hidden state remains visible enough in the parent view.
- [ ] Long labels and dynamic content have been stress-tested.
- [ ] Mobile-specific UI does not cause an obvious performance regression.

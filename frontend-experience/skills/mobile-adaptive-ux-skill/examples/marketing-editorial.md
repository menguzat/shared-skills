# Example - Desktop Marketing / Editorial Site to Mobile

This is an original illustrative scenario.

## Desktop
- wide header with 7 nav links
- 70vh hero
- side-by-side story modules
- hover image treatments
- newsletter form in footer

## Compact decisions

Navigation:
- keep one primary commercial CTA visible if genuinely dominant
- use compact menu for broader site sections
- do not add app-like bottom navigation unless recurring peer destinations justify it

Hero:
- reduce visual occupation so value proposition and next action appear without excessive initial scroll
- use a mobile-appropriate image crop/source rather than downloading/cropping only the desktop asset

Story modules:
- sequence based on editorial priority
- do not mechanically preserve desktop left/right alternation

Hover:
- decorative hover effects become optional capability enhancements
- content revealed only on hover becomes directly visible/tappable

Newsletter:
- semantic email input and autocomplete
- compact form with persistent label

# Brandbook Builder v1.1

Agentic skill package for creating brand strategy, visual identity systems, image-generation-led art direction, brandbook mockups, and production specifications.

## What is inside

- `SKILL.md` — executable agent workflow and routing.
- `references/` — detailed methods and research notes.
- `prompts/` — reusable image-generation prompt library.
- `templates/` — working templates for discovery, territory contracts, pages, QA.
- `examples/` — distilled case studies from the working process that produced this skill.

## Recommended use

1. Install/copy the whole directory as one agent skill.
2. Start with source material rather than aesthetic prompts.
3. Use image generation for exploration and art direction, not final typesetting.
4. Select one territory before expanding the complete brandbook.
5. Rebuild exact production assets deterministically after visual approval.

## Skill philosophy

Brand identity is treated as a visual/verbal operating system rather than a logo package. The skill is deliberately opinionated against generic AI-generated design defaults and against strategy built from unsupported adjective clouds.

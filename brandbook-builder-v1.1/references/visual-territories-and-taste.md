# Visual Territories, Taste & Anti-AI-Slop

## One direction is a system, not a mood

A valid visual territory must specify:
- type pairing/stance
- palette stance
- grid stance
- image stance
- material stance
- motion stance
- signature device
- prohibited moves

## Generate divergence deliberately

For 4 directions, vary axes such as:

| Axis | A | B |
|---|---|---|
| Structure | strict Swiss | loose editorial |
| Material | clean digital | physical/printed |
| Tone | refined | raw |
| Density | sparse | information-rich |
| Image | documentary | art-directed |
| Type | single grotesk | display + utility contrast |
| Motion | near-static | kinetic |

Do not make all directions “tasteful dark editorial.”

## Useful aesthetic archetypes

### Brutalist/raw
Visible structure, hard edges, strong type, few colors.

### Industrial/technical
Labels, readouts, mono/technical type, dense information, functional status color.

### Editorial
Asymmetric grids, captions, real typographic hierarchy, image rhythm.

### Refined/premium
Restraint, proportion, material, confident small type, space.

### Playful/adult
Scale shifts, movement, crop, participation; no toy iconography required.

### Organic/material
Humanist forms, actual material texture, non-synthetic color logic.

Blend two only when the brand tension supports it. Three-way aesthetic hedging usually creates genericity.

## AI-slop catalog: priority scan

### P0 — obvious defaults
- purple-blue gradient SaaS identity
- glass cards / glow everywhere
- Inter + generic blue by default
- untouched component-library appearance
- gradient text headlines
- “AI brain/network” hero imagery

### P1 — designer/developer tells
- rounded-2xl + shadow on every surface
- default max-width container composition
- icon in rounded-square repeated for every feature
- generic bento grid with dead cells
- identical left/right split sections
- decorative arrows on every CTA
- tiny uppercase meta-labels everywhere

### P2 — craft gaps
- flat spacing rhythm
- inconsistent optical alignment
- one animation repeated everywhere
- stock-photo color mismatch
- arbitrary texture
- poor text measure

## Taste tests

### Justified
Can every major decision be explained from brand strategy or function?

### Coherent
Do type, palette, grid, image, material, motion support the same worldview?

### Distinct
Could the same board plausibly be relabeled for three competitors?

### Operational
Can a non-originating designer use it tomorrow?

### Durable
Is it dependent on a short-lived design trend?

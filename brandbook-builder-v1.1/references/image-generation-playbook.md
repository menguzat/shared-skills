# Image Generation Playbook for Brand Identity

## Purpose

Use image generation to accelerate **visual reasoning** and **art direction**, not to replace deterministic identity production.

## Phase 1 — Territory exploration

Goal: discover coherent worlds.

Prompt should include:
- brand core idea
- productive tension
- design direction
- type stance
- palette philosophy
- grid/composition
- photography
- materials
- graphic devices
- 5–10 explicit negatives
- requested applications

Judge:
- recognizability
- hierarchy
- proportion
- world-building
- ability to expand

Ignore exact generated copy.

## Phase 2 — Focused system boards

After selection, split tasks:
- logo board
- type/color board
- graphic grammar board
- photography board
- social board
- signage/physical board
- digital board
- merch/packaging board

This produces better consistency than repeatedly asking for “one complete brandbook collage.”

## Phase 3 — Page-level generation

Generate pages/spreads with:
- exact page purpose
- approved identity summary
- content hierarchy
- fixed logo asset instruction
- references to prior selected direction
- explicit prohibition on redesigning established elements

## Phase 4 — Application proof

Generate the system inside realistic contexts:
- plausible dimensions
- plausible material
- real perspective
- real lighting
- restrained brand coverage

## Phase 5 — Production reconstruction

Rebuild approved outputs in Figma/Illustrator/InDesign/HTML/CSS/etc.

Do not rely on generated pixels for:
- exact logo geometry
- exact font
- legal copy
- QR code
- readable long text
- production dimensions
- accessibility validation

## Prompt grammar

Use this order:

1. **Artifact** — what is being generated?
2. **Brand truth** — what must it express?
3. **Chosen direction** — what visual system?
4. **Composition** — how is information organized?
5. **Typography** — character and hierarchy.
6. **Color** — role and scarcity.
7. **Photography** — subject/camera/light.
8. **Material** — texture/production.
9. **Applications** — what must be shown?
10. **Hard negatives** — what must not happen?
11. **Continuity** — what established elements must remain unchanged?

## Prompt correction protocol

When a generation is close, do not rewrite the whole brief. Issue a surgical correction:

> Preserve composition, palette, photography, spacing, grid and all approved elements. Change only [X]. Do not reinterpret [Y].

Useful surgical changes:
- replace logo only
- switch serif to characterful sans
- reduce vintage texture
- remove glass cards
- make typography more condensed
- keep page, replace images
- preserve page hierarchy, rewrite Turkish copy

## Image QA

Before approving:
- Is this clearly the same identity as the previous page?
- Has the generator invented another logo?
- Has the generator drifted to a familiar category cliché?
- Is generated text being mistakenly treated as final copy?
- Is texture hiding weak structure?
- Are applications physically plausible?

# Brand QA & Audit Rubric

Score 0–5 per dimension.

## A. Strategy

### Specificity
0 generic adjectives; 5 clearly differentiated position.

### Evidence
0 unsupported claims; 5 proof hierarchy explicit.

### Architecture
0 names/brands confused; 5 roles and endorsement clear.

### Durability
0 tied to current campaign; 5 can survive category growth.

## B. Verbal identity

### Native language
0 translated syntax; 5 reads as authored in primary language.

### Behavioral voice
0 adjective list; 5 concrete rules + examples.

### Claim discipline
0 hype; 5 claims calibrated to evidence.

## C. Visual identity

### Distinctiveness
0 competitor-template; 5 ownable grammar.

### Cohesion
0 collection of styles; 5 one system with controlled variation.

### Typography
0 default stack; 5 type has recognizable functional roles.

### Color
0 decorative palette; 5 role-based and operational.

### Photography
0 stock mood; 5 specific subjects/camera behavior tied to brand reality.

### Graphic grammar
0 sticker pile; 5 limited, repeatable vocabulary.

## D. Operational quality

### Applications
0 logo-on-mockup only; 5 real difficult touchpoints tested.

### Usability
0 beautiful but unusable; 5 clear rules an internal team can execute.

### Digital readiness
0 no states/tokens; 5 appropriate digital translation.

### Physical readiness
0 impossible mockups; 5 plausible material/production guidance.

### Governance
0 none; 5 fixed/flexible/versioning/approval defined.

## AI-slop failure scan

Mark Present / Absent:
- generic gradient
- glassmorphism
- rounded-card saturation
- default bento
- meaningless charts
- fake metrics
- generic AI symbols
- fashion-font reflex
- texture as camouflage
- repeated safe editorial aesthetic
- copywriting hype
- invented exact claims

## Priority

### P0
Identity-breaking: wrong official logo, false claims, unreadable mark, architecture error, inaccessible critical UI.

### P1
System friction: inconsistent type/color, generic applications, weak language, missing high-use touchpoint.

### P2
Polish: optical spacing, micro-alignment, secondary template refinement.

Fix P0 before adding new pages.

# Brandbook Architecture & Production

## Recommended core structure

Adapt to context; do not include irrelevant chapters.

1. How to use this book
2. Origin / reality
3. Brand idea / positioning
4. Purpose / vision / mission
5. Audience / jobs
6. Brand architecture
7. Character / principles
8. Verbal identity
9. Naming
10. Logo
11. Typography
12. Color
13. Grid / layout
14. Graphic devices
15. Iconography / illustration
16. Photography
17. Motion
18. Digital
19. Social/content
20. Physical
21. Product/packaging if relevant
22. Co-branding
23. Governance
24. Quick-reference rules

## Pacing

Alternate page types:
- Manifesto: sparse, memorable
- Strategy: explanatory
- Specification: precise
- Application: visual proof
- Editorial: story/photography

One main idea per page.

## Page anatomy

Each specification page should answer:
- what is this rule?
- why does it exist?
- how do I apply it?
- what does correct look like?
- what does incorrect look like?

## What belongs outside the master brandbook

Fast-changing information should become living manuals:
- current product catalog
- current prices
- campaign calendars
- jurisdiction-specific compliance
- live SKU rules
- current social cadence

Stable constitution stays in master brandbook.

## Deterministic reconstruction

When generated mockups are approved, produce exact layouts using production tools. Never deliver generated typography as a master identity asset.

# Example — Four Distinct Visual Territories

Hypothetical brand: a contemporary fabrication / learning space.

## Direction A — Public Workshop
- Type: condensed civic grotesk + utility sans
- Palette: bone, ink, safety orange
- Grid: municipal signage logic
- Photography: hard-flash documentary
- Device: workshop labels / dimensions
- Never: vintage industrial cosplay

## Direction B — Experimental Journal
- Type: neutral sans + strong editorial serif
- Palette: paper, black, one cobalt signal
- Grid: asymmetric publication
- Photography: quiet observational
- Device: captions / folios / crop
- Never: luxury-magazine emptiness

## Direction C — Working Protocol
- Type: technical grotesk + mono
- Palette: charcoal, warm gray, acid-green functional signal
- Grid: dense spec-sheet
- Photography: screens, tools, hands, process
- Device: status / indexing
- Never: fake hacker terminal

## Direction D — Open Yard
- Type: wide humanist sans
- Palette: mineral neutrals + field colors
- Grid: loose modular blocks
- Photography: daylight, people, materials, movement
- Device: painted directional marks
- Never: wellness/eco cliché

These qualify as separate territories because composition, type, image behavior and material logic change — not only colors.

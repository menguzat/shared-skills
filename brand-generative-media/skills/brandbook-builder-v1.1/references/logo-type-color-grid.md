# Logo, Typography, Color & Grid

## Logo

### Official mark handling
When an official master exists, use it exactly. A typed approximation is not a logo.

### Development sequence when no mark exists
1. black/white wordmark exploration
2. custom letter/rhythm intervention
3. compact derivative
4. optional secondary seal/stamp if earned
5. color application
6. production tests

### Tests
- 20 m signage
- 24–32 px digital
- embroidery
- stencil
- one-color print
- photocopy
- reverse
- partner lockup
- merchandise
- favicon/compact context

## Typography

Assign jobs, not just fonts.

### Display
Recognition, headlines, signage.

### Utility/text
Long reading, UI, information.

### Mono
Only if code/data/IDs/technical metadata are real parts of the brand.

### Editorial accent
Only if a distinct narrative voice is needed.

Specify:
- family and legal/licensing status
- weights
- Turkish character support
- fallback stack
- size/line-height/tracking
- optical rules
- print/digital differences

## Color

Assign semantic roles:
- canvas/foundation
- ink/text
- brand recognition
- action/signal
- status/function
- seasonal/program

Prefer role names over `purple-500` style names in the brandbook.

Do not assume color psychology is universal. Use category context, contrast, material provenance, and intended behavior.

### Accessibility
For digital systems, test text/background contrast and focus states. Brand expression does not override usability.

## Grid

Define a system that can generate variation:
- base unit
- columns
- gutters
- margins
- baseline rhythm if needed
- alignment rules
- intentional escape rules

A grid is successful when it produces recognizable structure without forcing every composition to look identical.

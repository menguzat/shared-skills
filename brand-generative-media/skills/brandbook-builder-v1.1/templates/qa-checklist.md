# Brandbook Final QA

- [ ] Reality and aspiration are separated
- [ ] Positioning is specific
- [ ] Proof is visible
- [ ] Architecture is accurate
- [ ] Negative identity exists

## Language
- [ ] Primary language is native-authored
- [ ] No translated syntax
- [ ] No unsupported hype
- [ ] Voice has behavioral rules
- [ ] Naming rules are coherent

## Logo
- [ ] Official master used
- [ ] Clearspace/min-size defined

- [ ] Partner context tested
- [ ] Physical reproduction tested

## System
- [ ] Typography jobs defined
- [ ] Color roles defined
- [ ] Grid creates variation

- [ ] Photography direction specific

## Applications
- [ ] Hard digital touchpoint tested
- [ ] Hard physical touchpoint tested
- [ ] Social/editorial tested
- [ ] Co-branding tested if relevant

- [ ] Fixed/flexible rules clear

# Logo & Typography Prompts

## Wordmark exploration

Design **6 genuinely distinct black-and-white wordmark directions** for **[BRAND NAME]**.

Do not create generic technology, sustainability, leaf, spark, brain, network, infinity, or abstract startup symbols unless the strategy explicitly requires one.

Express:
[TRAITS]

Explore meaningful differences in:
- width/proportion
- letter rhythm
- custom cuts
- terminals
- counters
- punctuation
- spacing
- condensed vs extended behavior

All directions must work at:
- facade/signage distance
- 32 px digital header
- one-color print
- embroidery/stencil
- partner lockup

Do not show six font substitutions. Each direction should have typographic authorship.

## Official-logo application

Use the supplied official **[BRAND]** logo exactly as provided. Do not redraw, approximate, typeset, simplify, or invent a substitute.

Apply it to [APPLICATION]. Preserve its geometry and proportions. You may change color only according to: [ALLOWED COLOR RULE].

## Typography system board

Create a brandbook typography board for [BRAND] using the approved visual system.

Define:
- display voice
- text/utility voice
- mono/data voice only if functionally relevant
- optional editorial accent only if justified
- Turkish glyph examples: Ç Ğ İ ı Ö Ş Ü ç ğ ö ş ü
- numerals and punctuation
- H1/H2/H3/body/caption/UI examples
- good/bad line length and tracking examples

The board must demonstrate real hierarchy, not merely font specimens.

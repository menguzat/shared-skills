# Master Visual Prompts

## 1. High-end visual territory board

Create a high-resolution professional brand identity direction board for **[BRAND]**.

This is not a generic moodboard, startup deck, or SaaS template. It should look like a senior independent identity studio exploring one coherent visual world.

**Brand truth**
[CORE IDEA]

**Productive tension**
[TENSION A] × [TENSION B]

**Direction name**
[DIRECTION]

**Typography stance**
[TYPE]

**Color philosophy**
[COLOR]

**Composition / grid**
[GRID]

**Photography**
[SUBJECT + CAMERA + LIGHT + MOVEMENT]

**Graphic grammar**
[1–3 DEVICES]

**Material behavior**
[MATERIAL]

**Motion character**
[MOTION]

Show:
- primary wordmark direction
- typography hierarchy
- 5–7 role-based color swatches
- 4 photographic frames
- 3 graphic-system examples
- one poster/editorial application
- one digital application
- one physical application

Hard negatives:
[NEGATIVES]

Do not use generic bento layouts, random glow, glassmorphism, AI brains/networks, meaningless charts, fake metrics, or arbitrary rounded-card UI unless explicitly required by the brand.

Every element must look chosen for this brand. Use purposeful variation rather than identical templates.

## 2. Surgical revision

Edit the approved **[BRAND]** direction.

Preserve exactly:
- composition
- grid
- image selection
- palette relationships
- spacing
- approved mark(s)
- all elements not listed below

Change only:
[CHANGES]

Do not reinterpret:
[LOCKED ELEMENTS]

The result should look like the same brandbook page after a senior designer's precise revision, not a new visual direction.

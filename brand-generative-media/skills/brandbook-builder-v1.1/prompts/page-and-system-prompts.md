# Brandbook Page & System Prompts

## Single brandbook page

Create a single high-resolution brandbook page for **[BRAND]**.

Page: **[NUMBER] — [TITLE]**

Purpose:
[PURPOSE]

Communicate:
[CONTENT]

Use the already approved identity without reinterpretation:
- logo: [LOCK]
- typography: [TYPE]
- palette: [PALETTE]
- grid: [GRID]
- graphic devices: [DEVICES]
- photography: [PHOTO]

The page must look like a continuous page from the same professional brandbook, not an independent poster.

Use one primary idea and a clear hierarchy. Generated text may be visually approximate; exact final copy will be typeset separately.

## Logo rules page

Create the official logo-system page showing:
- primary
- stacked/compact if approved
- reverse/one-color
- clearspace
- minimum size
- good uses
- prohibited transformations
- partner lockup
- signage + small digital proof

Use only approved mark geometry.

## Color/type/grid page

Create one technical but visually elegant system page that makes color roles, typography jobs and grid logic understandable to a designer/developer. Avoid decorative charts. Use real scale examples.

## Applications page

Create a page proving the identity across **at least four structurally different contexts**: [LIST]. Do not use the same layout pasted into four mockup frames.

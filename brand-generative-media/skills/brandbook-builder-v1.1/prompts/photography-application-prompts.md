# Photography & Application Prompts

## Photography art-direction board

Create a photography art-direction board for **[BRAND]**.

The brand behavior to reveal is:
[BEHAVIOR]

Photograph:
[SUBJECTS]

Camera behavior:
[CAMERA]

Lighting:
[LIGHT]

Framing:
[FRAMING]

Movement:
[MOVEMENT]

Acceptable imperfection:
[IMPERFECTION]

Include:
- one scale/architecture frame
- two human/action frames
- one material/detail frame
- one unexpected but on-brand frame

Avoid corporate team poses, generic stock smiles, perfect synthetic lifestyle scenes, commercial-ad gloss, and images that symbolize the concept instead of showing it happening.

## Physical signage/application

Apply the approved [BRAND] identity to **[REAL APPLICATION]**.

Production method: [PAINT / VINYL / EMBROIDERY / SCREEN PRINT / METAL / PAPER].

Show plausible scale, perspective, material response, wear, mounting and lighting. Do not brand every surface. The identity should look installed, printed, stitched or painted — not digitally pasted.

## Merch cultural test

Create a restrained [SWEATSHIRT / CAP / TOTE / PATCH] system for [BRAND].

The object should be desirable even to someone who does not know the brand. Avoid promotional-logo-placement thinking. Use the approved wordmark, type grammar and one secondary device only.

# Translation naturalization protocol

## Principle

A good translation should be independently readable Turkish.

The target reader should not need to reverse-engineer the source sentence.

## Stage 1 — Source comprehension

Before translating:
- identify facts;
- identify relations;
- identify tone;
- identify implication;
- mark wordplay;
- mark protected terminology;
- mark ambiguity;
- mark legal/technical operators.

If source is unclear, preserve/flag uncertainty instead of inventing clarity.

## Stage 2 — Translation unit

Do not translate isolated words unless building a terminology list.

Translate:
- sentence function;
- paragraph movement;
- UI task;
- rhetorical unit.

## Stage 3 — First Turkish reconstruction

Write the sentence as a Turkish writer could have written it without seeing the source.

You may:
- change word order;
- omit recoverable subject pronouns;
- split sentence;
- merge short fragments;
- repeat a semantic verb;
- change conjunction;
- turn noun phrase into verb;
- turn verb into noun if Turkish requires it.

## Stage 4 — Calque sweep

Search for:
- unnecessary `bir`;
- unnecessary pronouns;
- `olarak`;
- generic `yapmak`;
- long genitive chains;
- English punctuation rhythm;
- imported idiom;
- literal question structures;
- overly explicit subjects.

## Stage 5 — Terminology

Maintain a ledger:
`source term → approved target → prohibited variants → note`.

For domain-specific content:
- do not alternate synonyms for stylistic variety if they refer to one formal concept;
- use the same term consistently.

## Stage 6 — Back-check

Compare final Turkish against source for:
- missing facts;
- added facts;
- stronger/weaker claims;
- changed negation;
- changed time;
- changed quantity;
- changed agency;
- changed modality.

## Stage 7 — Monolingual read

Hide the source.
Read only Turkish.

Ask:
- Would a native writer choose this construction?
- Does any phrase smell translated?
- Is the emphasis where Turkish puts it?
- Can a shorter natural structure carry the same meaning?

## Translation fidelity levels

### `YAKIN`
Useful for language study, legal comparison, or source alignment.

### `DOĞAL` — default
Semantic fidelity + target-language naturalness.

### `TRANSCREATE`
Marketing effect + semantic truth. Syntax and metaphor may change.

## Headlines

Never translate a headline before understanding the page promise.

For a difficult line, generate internally:
1. semantic paraphrase;
2. plain Turkish headline;
3. brand-voice headline.

Select the most effective truthful version.

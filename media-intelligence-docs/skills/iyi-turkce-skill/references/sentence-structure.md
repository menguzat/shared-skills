# Sentence structure diagnostics

## Skeleton test

Strip:
- parentheticals;
- examples;
- subordinate detail.

Read:
`subject / topic → predicate`.

If broken, reconstruct.

## Attachment test

For each modifier ask:
`What exactly does this modify?`

Move it if two readings are plausible.

## Case harmony

Coordinated verbs can require different case suffixes.

Do not share one complement mechanically across verbs if each verb governs a different case.

## Long participle test

Turkish participles are powerful:
`... geliştirilen sistem`

But nested chains can force the reader to postpone the head noun too long.

When more than one layer of:
- `-dığı`;
- `-acak`;
- `-an`;
- `-mış`;
- genitive;
- possessive;
is stacked, inspect readability.

Split if the head noun arrives too late.

## Topic continuity

A paragraph may omit subjects elegantly when topic remains stable.

Reintroduce the noun when:
- another possible referent appears;
- paragraph changes actor;
- pronoun/suffix would be ambiguous.

## Sentence length

No universal word limit.

Use length as a diagnostic:
- 35+ words in web copy → inspect;
- 50+ → strong inspect;
- technical/legal contexts may justify.

Do not break a sentence solely to satisfy a count.

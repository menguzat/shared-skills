## Interpretation

The skill does not convert every book entry into a permanent rule.
It extracts recurrent reasoning patterns:
- identify what meaning is already encoded;
- remove accidental duplication;
- preserve purposeful emphasis;
- rebuild imported structures;
- inspect context;
- distinguish current convention from older prescription.

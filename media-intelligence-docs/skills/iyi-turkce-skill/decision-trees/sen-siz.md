# Decision tree: `sen` / `siz`

1. Existing brand/product convention?
   → follow it.

2. Formal B2B / regulated / broad unknown audience?
   → default `siz`.

3. Consumer brand deliberately intimate?
   → `sen` may fit.

4. UI label can work without explicit pronoun?
   → prefer pronoun-light imperative/label.

5. Context switches between `sen` and `siz`?
   → normalize.

Never infer intimacy merely to sound modern.

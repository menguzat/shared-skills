# Decision tree: Translation choice

1. Is target legal/technical comparison?
   → `YAKIN`.

2. Is ordinary article/document/UI?
   → `ÇEVİR` / faithful-natural.

3. Is headline/campaign/slogan?
   → `TRANSCREATE` if user permits adaptation.

4. Is source term standardized?
   → terminology ledger.

5. Is source wordplay essential?
   → preserve effect; explain tradeoff if needed.

6. Is source ambiguous?
   → do not resolve by guessing.

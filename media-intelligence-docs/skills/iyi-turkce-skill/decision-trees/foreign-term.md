# Decision tree: Yabancı terim

1. Is it an official product/API/standard/name?
   - Yes → preserve exact.

2. Is there a widely understood established Turkish equivalent?
   - Yes → prefer Turkish for general audience.

3. Does the professional audience primarily use the English term?
   - Yes → keep English or pair on first use.

4. Is discoverability/search important?
   - Yes → include both naturally on first use if useful.

5. Would a proposed Turkish equivalent sound invented/obscure?
   - Yes → do not force it.

6. Does the brand intentionally retain certain English terms?
   - Yes → project glossary wins.

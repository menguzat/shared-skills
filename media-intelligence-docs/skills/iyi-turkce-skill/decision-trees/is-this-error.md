# Decision tree: Hata mı, tercih mi?

1. Does it alter or obscure intended meaning?
   - Yes → HATA/RİSK depending severity.
   - No → continue.

2. Does current orthographic authority clearly prescribe a form?
   - Yes → HATA if ordinary current prose.
   - No → continue.

3. Is the form established in the target professional domain?
   - Yes → likely YERLEŞMİŞ KULLANIM.
   - No → continue.

4. Is the objection mainly stylistic/naturalness?
   - Yes → TERCİH or RİSK, not automatically HATA.

5. Is the unusual form deliberate voice, irony, dialect, historical quotation, or character speech?
   - Yes → preserve unless task requires normalization.

When uncertain, label uncertainty.

# Decision tree: `olarak`

1. Does it express a role/status?
   `mühendis olarak çalıştı` → keep.

2. Does it disambiguate manner/category?
   → possibly keep.

3. Is it attached to an adjective that can naturally modify the verb without it?
   → test removal/rewrite.

4. Is it a translation shadow of English `as` or `-ly`?
   → reconstruct relation.

5. Is it repeated nearby?
   → find stronger verbs/adverbs.

Do not ban `olarak`.

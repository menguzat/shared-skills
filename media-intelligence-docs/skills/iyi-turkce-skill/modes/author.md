# Mode: YAZ

Use when creating Turkish content from a brief.

## Workflow

1. Extract audience, destination, job, facts, constraints.
2. Build a one-sentence proposition.
3. Choose information order.
4. Draft in natural Turkish.
5. Run core Turkish pass.
6. Run destination pass:
   - web → scan;
   - UI → task;
   - brand → voice;
   - technical → precision.
7. Run claim/evidence check.
8. Run orthography check.
9. Read aloud where rhythm matters.

## Default

Do not narrate every writing decision.
Return finished copy unless rationale is requested.

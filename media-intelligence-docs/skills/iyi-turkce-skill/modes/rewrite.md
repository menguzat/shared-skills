# Mode: DÜZENLE

Purpose: improve an existing Turkish text without altering its factual or strategic content.

## Mandatory

- create semantic preservation inventory;
- keep technical literals exact;
- preserve intended register unless the request changes it;
- fix calques, redundancy, ambiguity, syntax, and rhythm;
- do not "improve" a cautious statement into an absolute claim.

## Rewrite strength

### LOW
Spelling, punctuation, local phrasing.

### MEDIUM — default
Naturalize syntax, shorten, fix flow.

### HIGH
Recompose paragraphs and information order while preserving content.

Use HIGH only if structure is materially weak or user asks for substantial rewriting.

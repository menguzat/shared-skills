# Mode: UX

## Order
1. identify user state;
2. identify desired action;
3. identify system state;
4. write minimum sufficient string;
5. check ambiguity;
6. check tone;
7. test pair/context.

## String requirements

Button:
- action visible.

Error:
- failure + recovery.

Warning:
- consequence.

Success:
- outcome.

Empty state:
- context + next action.

Do not import marketing voice into high-friction UI.

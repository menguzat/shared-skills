# Mode: ÇEVİR

Default target: Turkish that reads as original Turkish.

## Workflow

1. read full unit;
2. extract meaning/protected data;
3. identify source-language rhetoric;
4. draft Turkish without mirroring syntax;
5. run English-interference check;
6. normalize terminology;
7. back-check semantics;
8. monolingual Turkish read.

## Output

Return translation only unless:
- source is ambiguous;
- terminology choice matters;
- user asks for notes.

If ambiguity affects meaning, state it rather than guessing.

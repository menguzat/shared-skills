# Original examples — UX microcopy

## Upload failure

Weak:
`Bir hata oluştu.`

Better:
`Dosya yüklenemedi. Bağlantıyı kontrol edip yeniden deneyin.`

If file is preserved and system knows this:
`Dosya yüklenemedi. Bağlantıyı kontrol edip yeniden deneyin. Seçtiğiniz dosya korunuyor.`

---

## Delete

Weak:
`Emin misiniz?`
Buttons: `Evet` / `Hayır`

Better:
`"Hasat raporu" silinsin mi? Bu işlem geri alınamaz.`
Buttons: `Raporu sil` / `Vazgeç`

---

## Empty state

Weak:
`Henüz burada bir şey yok :)`

Better:
`Henüz rapor oluşturmadınız.`
CTA: `İlk raporu oluştur`

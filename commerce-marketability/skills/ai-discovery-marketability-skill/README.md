# AI Discovery, SEO, Recommendability & Agentic Marketability Skill

A deterministic agent skill for auditing, designing, implementing, and validating websites for:

- classical technical/content SEO,
- generative/answer-engine retrieval and citation eligibility,
- entity and proposition clarity,
- AI recommendation readiness,
- structured commerce discovery,
- agent-friendly interaction and transaction readiness,
- repeatable cross-model measurement.

The package intentionally separates **documented platform requirements**, **research-supported observations**, **inferences**, and **experimental hypotheses**. It does not promise rankings, citations, recommendations, traffic, or sales.

The core skill is `SKILL.md`. The experimental self-improvement subsystem is `subskills/ai-recommendation-lab/SKILL.md`.

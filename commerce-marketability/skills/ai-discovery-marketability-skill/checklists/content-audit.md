# Content Audit Checklist

For each important page:
- [ ] Primary entity/topic is unambiguous.
- [ ] Page has a clear user decision/job.
- [ ] Important facts are explicit in text/HTML.
- [ ] Values use units and dates where useful.
- [ ] Claims distinguish fact from opinion.
- [ ] Original evidence exists where possible.
- [ ] Tradeoffs/limitations are not hidden.
- [ ] Author/method/source is clear when relevant.
- [ ] Images/video add evidence or decision value.
- [ ] Internal links connect related entities/evidence.
- [ ] No generic filler dominates the page.
- [ ] No fake FAQ/keyword variation pages.

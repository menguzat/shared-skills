# Commerce Discoverability Checklist

- [ ] Stable product identifiers
- [ ] Canonical product URLs
- [ ] Product group/variant relationships
- [ ] Current price/currency
- [ ] Current availability
- [ ] Material/color/size/other relevant attributes
- [ ] Images with useful alt/context
- [ ] Shipping countries/cost/timing where available
- [ ] Returns policy
- [ ] Warranty/repair policy where applicable
- [ ] Lead time for made-to-order/preorder
- [ ] Product structured data
- [ ] Merchant feed where applicable
- [ ] OpenAI product feed eligibility checked where applicable
- [ ] Google Merchant Center checked where applicable
- [ ] Feed/page/schema consistency
- [ ] Update process for volatile fields

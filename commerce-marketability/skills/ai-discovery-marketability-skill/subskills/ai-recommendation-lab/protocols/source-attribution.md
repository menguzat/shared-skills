# Source Attribution Protocol

When a response uses live web/search, capture every visible citation/source.
For target-source analysis record:
- first-party target domain,
- independent editorial source,
- forum/community,
- retailer/marketplace,
- directory/database,
- documentation/standards,
- unknown.

Track which propositions appear to be supported by which source types, but do not infer hidden retrieval logic beyond observed evidence.

# Minimal Statistical Protocol

Always report numerator/denominator.
For binary outcomes use a binomial confidence interval where practical.
For paired before/after prompts, prefer paired comparisons.
For ranking outcomes, preserve full ordered list rather than collapsing immediately to a scalar.

Do not declare “improvement” when:
- model version changed and cannot be controlled,
- search mode changed,
- competitor set changed materially,
- prompt family changed,
- sample is too small to distinguish noise.

Treat effect estimates as local to the tested setup.

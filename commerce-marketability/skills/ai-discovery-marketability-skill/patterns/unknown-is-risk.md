# Pattern: Unknown Is Recommendation Risk

When a user applies hard constraints, missing information can make a candidate unsafe to recommend.

Audit unknowns in:
- price,
- availability,
- materials/components,
- compatibility,
- shipping,
- returns,
- timing,
- size/fit,
- location,
- certification/status.

Prioritize exposing real values. Never fill unknowns with guesses.

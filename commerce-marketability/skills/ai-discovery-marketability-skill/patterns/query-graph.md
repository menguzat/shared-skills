# Pattern: Query Graph, Not Keyword List

Model connected intents and constraints. One user's broad query may generate several retrieval subqueries inside AI/search systems. Build a content architecture that covers the decision domain naturally rather than one URL per phrase.

Graph nodes: problem, category, feature, constraint, comparison, trust, transaction, post-purchase.
Edges: “requires”, “compares with”, “qualifies by”, “evidenced by”, “purchased via”.

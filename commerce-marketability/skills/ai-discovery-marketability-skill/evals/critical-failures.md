# Critical Failures

Any of these fails the skill evaluation regardless of score:

1. Inventing a business/product fact.
2. Recommending fabricated authority, reviews, citations, awards, or certifications.
3. Promising a ranking/citation/recommendation result.
4. Treating one AI response as a stable ranking fact.
5. Treating a citation experiment with supplied context as proof of organic retrieval.
6. Adding schema/feed values that contradict the visible page or real catalog.
7. Mass-generating thin pages merely to capture prompt variants.
8. Allowing the lab to silently rewrite production rules from unreplicated experiments.

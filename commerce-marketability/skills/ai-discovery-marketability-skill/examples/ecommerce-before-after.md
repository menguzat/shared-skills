# Example: Specialist Apparel Product

## Before
“An extraordinary natural overshirt combining timeless elegance with artisan craftsmanship.”

Problems:
- category is vague,
- material composition absent,
- price/lead time/shipping absent,
- fit/customization absent,
- no proof,
- no machine-comparable decision variables.

## After architecture
Visible product facts include:
- 100% linen, 185 GSM,
- woven/cut locations if verified,
- made-to-order status,
- exact measurement/customization options,
- production lead-time range,
- shipping geographies,
- return/alteration policy,
- construction/material components,
- care/shrinkage test if actually performed,
- current price/currency,
- evidence links.

Narrative brand copy can remain, but it does not replace qualification data.

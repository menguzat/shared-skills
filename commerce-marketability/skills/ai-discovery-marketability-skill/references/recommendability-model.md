# Recommendability Model

Recommendation is modeled as conditional fit, not a global score.

Conceptual objective:

P(recommended | engine, query, user constraints, candidates, retrieved evidence, geography, current state, time)

Audit stages:
1. candidate discovery,
2. qualification,
3. comparative ranking,
4. evidence/trust,
5. user fit,
6. action feasibility.

Useful dimensions include price, materials, compatibility, availability, lead time, delivery geography, size, customization, return/warranty/repair policy, verified quality evidence, provenance, ratings/reviews when genuine, and use-case suitability.

A brand should seek factual, machine-visible, decision-relevant differentiation rather than generic superlatives.

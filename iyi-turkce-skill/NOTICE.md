# Notice and source boundaries

## Necmiye Alpay — *Türkçe Sorunları Kılavuzu*

The user supplied a copy of:

Necmiye Alpay, *Türkçe Sorunları Kılavuzu*, Metis Yayınları, gözden geçirilmiş 7. basım, 2021.

The book is copyrighted. This package does not redistribute the PDF or reproduce its dictionary-like contents. It contains an original, task-oriented synthesis of selected linguistic principles, with short diagnostic examples rewritten or newly created.

The source itself states that Turkish usage changes, that not every rule has universal consensus, and that context matters. This package preserves that non-dogmatic distinction.

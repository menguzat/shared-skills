# Decision tree: `bir`

For each `bir`:

1. Does it mean numeral "one"?
   - Keep.

2. Does it establish a genuine indefinite individual/item?
   - Usually keep.

3. Is it part of an idiom/fixed expression?
   - Keep unless context says otherwise.

4. Does it create rhetorical rhythm/emphasis?
   - Keep deliberately.

5. Did it appear because source English has `a/an`?
   - Test deletion.

6. Does deletion preserve meaning and improve naturalness?
   - Delete.

Never mass-delete `bir`.

# Decision tree: Yaratıcılık mı açıklık mı?

1. Is the text a control, warning, error, checkout, legal, safety, or instruction?
   → clarity wins; creativity minimal.

2. Is it hero/brand/campaign/editorial?
   → creativity allowed.

3. Does creative line still communicate category/proposition?
   - Yes → keep.
   - No → add clear supporting line or replace.

4. Does metaphor imply an unsupported fact?
   - Yes → reject.

5. Does cleverness depend on English?
   - Yes → transcreate or remove.

6. Does the section already contain another strong rhetorical device?
   - Yes → reduce.

# İyi Türkçe — Agentic Writing Skill

A Turkish-language authoring, editing, web-copy, UX-writing, brand-copy, and translation skill.

The package combines four layers:

1. **Language diagnosis** — derived from Necmiye Alpay's *Türkçe Sorunları Kılavuzu* without redistributing the book.
2. **Current orthography** — current TDK spelling/punctuation is the live authority for uncertain forms.
3. **Digital content design** — scan-first, task-first, concise web and interface writing.
4. **Bold brand voice** — an evidence-led systems/material profile inspired by LYF.lab's public communication.

## Default behavior

`ÇEVİR` means faithful-natural translation, not word-for-word translation.

`DÜZENLE` preserves meaning and claims while making the Turkish sound native.

`DENETLE` reports issues without silently rewriting the entire artifact.

`LYF-BOLD` creates bold, concise, systems-oriented brand language but cannot invent evidence or strengthen unsupported claims.

## Install

Copy this folder into the agent's skill directory and activate `SKILL.md`.

## Source policy

This skill contains original synthesis, rules, decision trees, and examples. It does **not** include the source book. See `NOTICE.md` and `references/source-registry.md`.

# Mode: SEO-WEB

Use with a separate SEO strategy if available.

## Goal
Natural Turkish that is discoverable without keyword-stuffing.

## Workflow
1. identify user intent;
2. identify topic/entity names;
3. map real questions;
4. write direct answer;
5. expand with evidence;
6. structure with descriptive headings;
7. verify terminology;
8. keep inflection natural.

## Never
- repeat malformed query phrases;
- avoid suffixes to preserve "exact match";
- stuff city/product/category strings;
- write headings for crawler rather than reader.

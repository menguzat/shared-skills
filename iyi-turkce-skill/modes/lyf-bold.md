# Mode: LYF-BOLD

Apply only to contexts where a brand voice is appropriate.

## Draft sequence

1. State one sharp proposition.
2. Challenge the conventional frame if useful.
3. Ground in material/process/system fact.
4. State consequence.
5. End before the concept becomes manifesto fog.

## Intensity levels

### 1 — restrained
Mostly plain copy with one strong thesis.

### 2 — standard
Thesis + contrast + proof.

### 3 — campaign
More rhythm, rhetorical structure, transcreation.

Never exceed evidence.

# Mode: MARKA

Use a supplied voice guide if available. If not, define one before large-scale brand writing.

## Minimum brand brief
- category;
- audience;
- proposition;
- 3 voice traits;
- 3 anti-traits;
- proof;
- prohibited claims;
- preferred terminology;
- `sen/siz`.

## Output rule
A brand sentence can be distinctive without becoming obscure.

If a line needs explanation to reveal what the company does, provide an immediate supporting line.

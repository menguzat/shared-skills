# Türkçe Sorunları Kılavuzu — agent-oriented synthesis

This is a synthesis, not a reproduction of the source.

## 1. Context before policing

The source repeatedly treats language as contextual and evolving. It acknowledges disagreement among language authorities and notes that forms considered problematic can later become established.

Agent rule:
- classify before correcting;
- distinguish hard error from stylistic risk;
- do not use "yanlış" for every non-preferred form;
- inspect actual sentence meaning and register.

## 2. Turkish carries information in suffixes

Turkish often does not need explicit pronouns where inflection already identifies person or possession.

Agent diagnostic:
- inspect `o/onun/onlar/onların` and equivalents;
- ask whether they add contrast or merely repeat a suffix;
- check whether unnecessary pronouns create false contrast or ambiguity.

## 3. Semantic duplication is a major failure class

The book repeatedly diagnoses constructions that encode one concept twice.

General categories:
- cause + causal postposition;
- possibility suffix + possibility noun;
- ability suffix + ability noun;
- noun whose meaning already contains a modifier;
- repeated plural information;
- repeated possession;
- verb + unnecessary process noun.

Agent rule:
- remove duplicated semantics, not rhetorical repetition;
- preserve repetition that carries emphasis, rhythm, irony, contrast, or lexicalized meaning.

## 4. `bir` is not an article token

English and some other Western languages structurally require articles in positions where Turkish does not.

Agent rule:
- for every `bir`, identify its function;
- remove it if it entered solely as an `a/an` shadow;
- retain it when it means one, a particular indefinite instance, approximation, emphasis, or is idiomatic.

## 5. Word-for-word translation produces "correct words, wrong Turkish"

The source's translation examples repeatedly show that literal mapping can create phrases that are understandable but not idiomatic Turkish.

Agent rule:
- translate proposition and discourse function;
- rebuild sentence using Turkish syntax;
- challenge default mappings such as `or → ya da`, `do → yapmak`, `as → olarak`.

## 6. Reuse the real verb

English can use `do/did` to stand in for a previous verb. Turkish often prefers the original verb.

Agent check:
- if `yapmak` merely substitutes an earlier action, restore the semantic verb.

## 7. Subject–predicate skeleton matters

Long openings, appositives, and inserted phrases can cause writers to abandon the grammar promised at the beginning of a sentence.

Agent check:
- remove parentheticals mentally;
- read only the sentence skeleton;
- verify subject, case, person, number, and predicate relation.

## 8. Double passive

Passive morphology can accidentally be applied twice or stacked redundantly.

Agent check:
- inspect verbs that feel mechanically "more passive";
- use one passive mechanism where one is enough.

## 9. Precision is not certainty

The source distinguishes clear language from unjustified certainty, especially in scientific discourse.

Agent rule:
- make uncertainty precise;
- never delete qualifiers simply to sound strong;
- clarity can include `olabilir`, `görünüyor`, confidence intervals, or explicit limits.

## 10. Emphasis is structural

Turkish can create emphasis using:
- word order;
- proximity to predicate;
- pronouns;
- `bir`;
- plural;
- commas;
- repetition;
- intensifiers.

Agent rule:
- before adding emphasis words, ask whether syntax can carry the emphasis more naturally.

## 11. Meaning relations before surface forms

Possessive constructions can be semantically ambiguous:
- information *about* X;
- information *contained in* X;
- information *owned/known by* X.

Agent rule:
- name the relation explicitly (`X'e ilişkin`, `X'teki`, etc.) when a genitive could be read multiple ways.

## 12. Current-usage override

The source itself notes language change.

Therefore:
- use it to spot questions;
- use current TDK and domain usage to resolve current spelling;
- use context to resolve register and accepted professional terminology.

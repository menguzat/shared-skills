# Source registry

## Primary linguistic source supplied for this project

### Necmiye Alpay — *Türkçe Sorunları Kılavuzu*
- Edition inspected: revised seventh edition, 2021.
- Role: diagnostic language-awareness source.
- High-value areas used by this skill:
  - English interference and "Hollywood Turkish";
  - pronoun redundancy;
  - unnecessary `bir`;
  - semantic duplication;
  - subject–predicate problems;
  - double passive;
  - ambiguity;
  - emphasis;
  - punctuation and modifier relationships;
  - distinction between questionable and established usage.
- Authority boundary: not used as the sole current orthographic authority.

## Digital writing

### Google Material — UX writing
https://codelabs.developers.google.com/codelabs/material-communication-guidance?hl=tr

Useful principles:
- write for user journeys;
- concise and clear UI text;
- audience/context determine tone;
- online text is less formal and space-constrained;
- readers scan;
- descriptive headings and short paragraphs;
- terminology lists improve consistency.

### Google Technical Writing
https://developers.google.com/tech-writing/one/short-sentences

Useful principles:
- one primary idea per sentence;
- split complex lists into lists;
- remove extraneous words;
- prefer precise verbs over noun-heavy phrases.

### MEB electronic-content criteria
https://ttkb.meb.gov.tr/kriter/

Useful principles:
- correct and careful Turkish;
- clarity, simplicity, fluency;
- avoid structural/semantic errors;
- remove unnecessary repetitions;
- prefer current TDK for general orthography;
- context-appropriate terminology.

## Brand voice observations

- https://thelyflab.com/

Observed public tendencies:
- short declarative theses;

- contrast;
- material/process language;
- origin-to-system thinking;
- claims linked to process/evidence more often than generic lifestyle adjectives.

## Refresh policy

Web sources can change.

Before high-stakes or long-lived publication:
1. recheck TDK for disputed spellings;
2. recheck actual project terminology;
3. re-sample current brand copy if the voice profile matters;
4. do not preserve an old rule merely because it is bundled here.

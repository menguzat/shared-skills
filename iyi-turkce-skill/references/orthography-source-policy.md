# Orthography and source policy

## Current spelling

Use current TDK live sources for uncertain general-language forms.

Primary:
- TDK Yazım Kılavuzu
- Güncel Türkçe Sözlük

## Do not hard-code historical disagreement

The supplied 2021 guide is valuable for diagnosis but cannot freeze Turkish spelling forever.

If bundled advice conflicts with current TDK:
- use current TDK for general orthography;
- record project exception if the brand deliberately differs.

## Domain terminology

For scientific/technical terms:
1. project glossary;
2. applicable standard;
3. domain-accepted Turkish usage;
4. TDK terminology resources where appropriate.

Do not "correct" a standard product/API name.

## Quotation integrity

Never silently correct:
- quotations;
- historical text;
- legal excerpts;
- UI strings quoted as evidence.

Use `[sic]` only when editorial context requires it; do not overuse.

## Headline capitalization

The skill's default sentence-case web heading is a project style choice.

If publication style requires title case or another capitalization scheme, follow it consistently.

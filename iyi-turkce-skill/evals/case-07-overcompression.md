# Case 07 — semantic duplication vs. real distinction

Input:
`Ürün yalnızca çevrimiçi kanallarda satılabilir.`

Task:
Shorten.

Hard fail:
`Ürün çevrimiçi satılır.`

Why:
- loses `yalnızca`;
- changes possibility/permission `satılabilir` to factual present `satılır`.

Expected:
keep semantic operators.

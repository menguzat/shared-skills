# Critical Failures

Automatic failure if the agent:

- edits before obtaining a runnable baseline when one is possible;
- reports a single/best Lighthouse score as proof of improvement;
- serves benchmark-specific content to Lighthouse;
- disables essential functionality solely for score;
- claims TBT proves INP passes;
- retains a performance patch after a critical flow regression;
- lazy-loads a proven LCP image;
- ignores a major visual/accessibility regression;
- deletes unrelated user code or resets working tree destructively;
- asserts a field performance improvement without field evidence.
